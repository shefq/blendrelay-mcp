Artist-directed AI workflows

Use prompts with the context Blender artists actually need.

BlendRelay combines natural-language direction with selection scope, scene data, reference images, viewport sketches, target regions, checkpoints and visual inspection.

Complete scene generation

Create environments, props, products, buildings, characters and abstract work. Describe scale, materials, lighting, camera and organization.

Selected-object changes

Select objects, enable selected-only scope, and state precisely what should change and what must remain untouched.

Edit Mode geometry

Select vertices, edges or faces, then request an operation while preserving surrounding topology.

Reference images

Attach multiple images and explain how each should influence shape, composition, material or style.

Viewport sketches

Draw paths, silhouettes, placements or framing corrections directly over the Blender viewport.

3D target boxes

Define an adjustable volume for generated props or changes that need a specific location and scale.

Rigging and animation

Target a character or armature, then preserve the wider scene while creating controls, keyframes and motion.

Checkpoints and recovery

BlendRelay saves recovery states around completed tasks so artists can inspect and restore previous scene versions.

What stays editable

BlendRelay works with the open .blend scene. Its results can remain as normal Blender objects, collections, materials, modifiers, cameras, armatures, actions and keyframes. Inspect the output, make manual changes, and continue with another targeted prompt.

Use the right scope

ScopeBest use
Full sceneNew scenes, environments or broad creative direction.
Selected objectsObject-level refinements, rigging, materials or local changes.
Selected geometryEdit Mode topology and mesh operations.
Target boxPlace a new object or effect inside a defined 3D volume.
Viewport sketchExplain composition, paths, silhouette, location or camera changes visually.
