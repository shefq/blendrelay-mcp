Open source

Bring AI agents into an editable Blender workflow.

BlendRelay MCP is a Blender add-on and MCP server built to make prompt-based 3D work more visual, controllable and practical for artists.

Project purpose

BlendRelay connects the open Blender scene to supported AI agents through typed MCP tools. The objective is not to replace Blender craft, but to make creation, local changes, iteration and scene exploration faster while keeping the work inspectable in Blender.
