Demonstrated workflow

From a city prompt to an animated dragon flight.

The dragon-city demonstration follows one connected Blender project: a cinematic scene, a selected-dragon armature, a target-box prop, a sketch-guided camera correction, and selected-armature flight animation.

1Generate a New York-inspired rooftop city and perched dragon.
2Select the dragon and create a rig with leg, head, jaw, tail and wing controls.
3Place a blue-flame bronze brazier inside a marked 3D box.
4Use a viewport sketch to correct an inverted, overly tight camera animation.
5Select the armature and create coordinated full-body flight motion.

Start in minutes

Install the package, enable the add-on, then connect Blender.

You need Blender 4.5 or newer, uvx or Python 3.11+, and one supported AI command-line agent that is already installed and signed in.

uvx blendrelay-mcp setup
