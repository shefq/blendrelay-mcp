Artist guide

Give the agent clear direction and keep control of your scene.

Use this guide for the practical workflow inside the BlendRelay Blender panel and HUD.

Your first creation

  1. Select an agent and model.
  2. Choose Full Scene for a new scene.
  3. Describe the subject, scale, style, materials, lighting, camera and required separate parts.
  4. Run the agent and inspect the result in Blender.
Create a polished studio product scene for a modern wireless speaker. Use a dark graphite body, a woven fabric grille, soft bevels, realistic PBR materials, an 85 mm product camera and a clean charcoal background.

Edit existing work

Select one or more objects, enable selected-object scope, then state what must change and what must remain. For mesh work, enter Edit Mode, select geometry, and enable selected-geometry scope.

Only edit the selected chair. Make the backrest 15% taller, soften the outer edges, replace the upholstery with dark green velvet, and preserve its location and dimensions.

Use references, sketches and target regions

Attach one or more references from the panel or drag them over the viewport. Explain the role of each image. Draw viewport strokes for paths, placement, silhouettes or corrections. Use a target box where a new object must fit inside a defined volume.

Choose a generation profile

ProfileBest for
Focused TaskContained selected-object or geometry edits.
Full CreationA complete object or moderately detailed scene.
Creation + AssetsScenes that should search enabled asset providers.
Complex ProductionLarge scenes, multi-stage builds, animation or detailed verification.

Checkpoints

BlendRelay saves recovery checkpoints before a task and after successful completion. Open Versions to inspect or restore a saved scene state. Save your main .blend file normally as well.
